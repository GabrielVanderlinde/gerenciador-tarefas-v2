# Gerenciador de Tarefas v2

Segunda versão de uma aplicação Java de linha de comando para organização de tarefas. O projeto pratica programação orientada a objetos e manipulação de datas, com identificadores para localizar e editar tarefas.

## Tecnologias

- Java
- `LocalDate` para datas
- `ArrayList` e coleções Java
- Programação Orientada a Objetos

## Funcionalidades

- Cadastrar tarefas com título, descrição e data
- Editar tarefas por identificador
- Listar tarefas
- Trabalhar com datas no formato `dd/MM/yyyy`

Consulte as classes em `src/` para verificar todas as operações disponíveis nesta versão.

## Como executar

Instale um JDK e clone o repositório:

```bash
git clone https://github.com/GabrielVanderlinde/gerenciador-tarefas-v2.git
cd gerenciador-tarefas-v2
```

Compile os arquivos Java:

```bash
javac src/*.java
```

Execute a classe principal indicada em `src/Main.java`.

## Objetivo

Evoluir os fundamentos de Java, orientação a objetos, validação de entrada e manipulação de datas.
